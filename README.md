# ResumeIQ

## Build a Resume That Matches the Job

ResumeIQ is an AI-powered resume analysis and job matching platform designed to help users understand, improve, and optimize their resumes for specific job opportunities.

## Features

Resume Analysis

Analyze resumes uploaded in PDF or DOCX format.

ATS Analysis

Evaluate resume structure, content, and ATS compatibility.

Job Matching

Compare resumes against specific job descriptions.

Skill Gap Analysis

Identify matched skills, missing required skills, and missing preferred skills.

AI Recommendations

Get personalized suggestions to improve resume quality and job relevance.

Resume Optimization

Generate job-specific recommendations for improving resume content.

Resume Version Management

Create and manage different resume versions for different job opportunities.

User Authentication

Secure sign-in and account management.

Analysis Dashboard

View resume scores, matching results, skills, and recommendations.

Resume Export

Export optimized resume versions.

## Tech Stack

Frontend: React.js, JavaScript, HTML, CSS

Backend: Python, Flask

Database: SQLite

AI and NLP: AI-powered resume and job description analysis
